West Bank / Table

An open-source restaurant guide for Cedar-Riverside, Minneapolis. Find dining options near Hanson Hall that fit your dietary preferences and budget.

Features
Interactive map with a Hanson Hall reference pin
Dietary filters for halal, vegetarian, vegan, and gluten-free options
Restaurant descriptions with estimated meal prices
Searchable directory with a download option
About the information

Map locations are approximate. Prices may change, and ratings reflect available snapshots. Dietary information comes from published restaurant sources. The Hanson Hall pin is a fixed reference point rather than your live location.


Access and reuse

Open the dashboard in your browser. No installation is required.
